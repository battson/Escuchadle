Conversor de clips — herramienta local

Corta un fragmento de 20s de cada canción del catálogo (desde el segundo ini) usando yt-dlp + ffmpeg, para no depender de llamar a YouTube en vivo. Necesita correr con un servidor PHP local (php -S localhost:8899 desde la raíz del repositorio) — no funciona abierto como archivo suelto ni publicado en GitHub Pages. Ver README.md de esta carpeta.
