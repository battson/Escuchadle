Verificación del catálogo

    

      
      
      
      
    

    
Tocá Verificar para revisar el catálogo. Va de a una canción por vez para no saturar la API de YouTube, así que unas 64 canciones tardan cerca de un minuto. Lo encontrado queda guardado en este navegador: si lo parás, o si se corta, al volver a tocar Verificar sigue desde donde quedó sin repetir búsquedas.


    Cada fila muestra qué video eligió la búsqueda. Tocá ▶ para abrirlo en YouTube y confirmar. Si alguno está mal, copiá el ID correcto de la URL (watch?v=ID) y ponelo en el catálogo como yt:"ID". "Copiar catálogo con IDs" te da el array entero ya fijado, listo para reemplazar; después de eso la clave de API deja de ser necesaria.

    
Cómo obtener la clave (gratis, 5 min): console.cloud.google.com → crear proyecto → "APIs y servicios" → habilitar YouTube Data API v3 → "Credenciales" → crear clave de API. Copiá js/config.example.js como js/config.js y pegala ahí. La cuota gratuita alcanza para ~100 búsquedas por día, suficiente para verificar todo el catálogo de una vez.
