Cómo se juega

Suena un pedacito de una canción argentina y tenés seis intentos para decir cuál es. Hay una sola por día y es la misma para todo el mundo.

  1. Escuchá. Tocá ▶ Escuchar (o apretá la barra espaciadora). La primera vez suena un segundo nada más.
  2. Tirá tu apuesta. Escribí en el buscador: te va sugiriendo canciones del catálogo. Elegí una de la lista y tocá Enviar.
  3. Si errás, ganás tiempo. Cada intento fallido alarga el fragmento: 1 · 2 · 4 · 7 · 11 · 16 segundos.
  4. ¿No se te ocurre nada? Saltar te gasta un intento, pero te destraba los segundos siguientes sin arriesgar.
Qué significa cada color
  • Le pegaste: canción y artista.
  • Acertaste el artista, pero no la canción.
  • Ni una cosa ni la otra.

Las pistas

Son tres y aparecen recién sobre el final, una por intento, cuando ya te quedan pocas balas:

  • 4.º intento — el género de la canción.
  • 5.º intento — cuántas palabras y letras tiene el título.
  • 6.º intento — cuántas palabras y letras tiene el artista.

Hasta entonces las vas a ver con candado 🔒, para que sepas qué se viene.

La tabla

Al terminar podés poner tu nombre y tocar Enviar al ranking. Recién ahí tu partida entra en la tabla: si no lo tocás, no figurás. Se mira cuando quieras con el 🏆 de arriba, y tiene dos vistas, la de hoy y el histórico.

El audio sale del reproductor oficial de YouTube. Si cerrás la página, la partida del día te queda donde la dejaste.

Modo de juego

    

      
      
    

    
El modo libre saca una canción al azar, no guarda la partida y no cuenta para las estadísticas. Solo se puede entrar desde acá.

  


  

    
Verificación del catálogo

    

      
      
      
      
    

    
Tocá Verificar para revisar el catálogo. Va de a una canción por vez para no saturar la API de YouTube, así que unas 64 canciones tardan cerca de un minuto. Lo encontrado queda guardado en este navegador: si lo parás, o si se corta, al volver a tocar Verificar sigue desde donde quedó sin repetir búsquedas.


    Cada fila muestra qué video eligió la búsqueda. Tocá ▶ para abrirlo en YouTube y confirmar. Si alguno está mal, copiá el ID correcto de la URL (watch?v=ID) y ponelo en el catálogo como yt:"ID". "Copiar catálogo con IDs" te da el array entero ya fijado, listo para reemplazar; después de eso la clave de API deja de ser necesaria.

    
Cómo obtener la clave (gratis, 5 min): console.cloud.google.com → crear proyecto → "APIs y servicios" → habilitar YouTube Data API v3 → "Credenciales" → crear clave de API. Copiá js/config.example.js como js/config.js y pegala ahí. La cuota gratuita alcanza para ~100 búsquedas por día, suficiente para verificar todo el catálogo de una vez.
